# Workbench studio refinement

The user's light 3D editor references are the visual authority for this pass. Keep the YAB3D mark and every existing export capability. This is an isolated test release; production is unchanged.

The first viewport is a large, pale model canvas, a small tool island at its top and one quiet inspector. Select, Colour, Split and Arrange operate on the same selection. Project and export settings remain available without interrupting that flow. Selection is visible on the canvas and in the object list. Only the current operation exposes Apply and Cancel.

Use neutral white and cool grey, dark ink, and restrained green for selection and the main action. Avoid stacked toolbar bands, duplicate actions, long instructions above the model and decorative cards. Keep the current model title visible. The inspector owns scrolling. Short explanations sit next to consequential choices.

Motion: a short, gentle context-panel arrival and tactile button press. No motion delays a result, and reduced-motion disables it. Busy work always has a visible progress message.

Geometry changes must reach the downloaded 3MF, preserve unrelated objects, paint and settings, and be undoable. Colour replacement affects selected copies only. Separate existing parts and planar cuts are explicit operations; never label an open colour surface as a printable solid. Reject unsupported cuts before replacing the current model.

The colour-separation extension stays inside Split: highlight an original painted region, keep both resulting parts or remove that region, and optionally add a locating pin with a matching socket. Use the actual region boundary, including shallow curved seams where both caps can share a mating surface. Reject flat paint patches, invalid boundaries and insufficient material. Single-colour whole-object selection remains in Select, with wording that distinguishes it from removing paint regions. Keep Apply and Cancel visible while dimension settings scroll, on desktop and mobile. This extends the incumbent design rather than establishing a new visual system.

The orientation follow-up turns the pin-bearing part upwards by default, with an explicit opt-out. Painted regions of a shared colour are chosen separately: black arms and white hands must not be implicitly bundled, and black eyes must remain untouched when an arm is chosen. Unsafe paint boundaries show an explanation and cannot be applied. Arrange offers one Print layout choice for together, separate colour plates, or sequential colour groups. Prepared jobs stay in the inspector with individual downloads and the existing primary download action. This is an ordinary extension of the same visual system, not a new design direction.

References inspected: the user's two videos and four UI images; Shapr3D's adaptive selection menus (https://support.shapr3d.com/hc/en-us/articles/7873882619548-Adaptive-user-interface); Prusa's distinction between separate objects and attached parts (https://help.prusa3d.com/article/cut-tool_1779).

Validate desktop and mobile together, including a loaded project, selected-object controls, colour preview/cancel, split/export round trips, undo and reduced motion. Build and deploy only the workbench-test alias.

Additional research: Refero's Spline editor (https://refero.design/pages/58c29774-a6e3-4de2-a899-5dd25b79d815) and Womp examples, and Mobbin's Figma web collection (https://mobbin.com/apps/figma-web-1f89f45c-7564-44a0-9696-31df9b6310f8/10aa7650-e5d6-498b-9b34-3af156c8ed89/screens). Observed patterns: a compact tool island over the canvas, stable object list, and precise contextual properties. These inform hierarchy; no third-party screenshots or assets ship in the app. Open Design was not available through the connected tools.
