# Three PLA colours and a PETG support interface — review demo

Open `recolour.html?interface=petg` and choose **Try the four-colour support arch**, or load a painted 3MF. The generated arch is an original, reusable test model; it contains no uploaded user geometry.

The checkbox reserves physical slot 4 for PETG. Model-first suggestions search sets of three PLA colours; loaded-filament mode keeps slots 1–3 fixed. The interface reel is excluded from solid colour matching, exact-colour locks and blend ingredients. Its own colour and PETG preset remain editable. Slots 1–3 can be rearranged; slot 4 is fixed in this demo.

Review the original versus predicted colour, apply the palette, accept the colour review, then download. Extra Full Spectrum entries are virtual recipes using only slots 1–3, not extra physical reels. The export carries three PLA profiles, one PETG profile, and matching global/object interface overrides:

- Supports enabled, retaining the source support style and painting.
- PLA slot 1 for the support structure; PETG slot 4 for the interface.
- Three dense top/bottom interface layers, zero top/bottom Z distance.
- Prime tower enabled, with its shell assigned to PLA slot 1.

These are demonstration starting settings, not a filament-calibrated print preset. Supports are generated by the slicer and do not appear in the model preview. Check the sliced contact layers and test a small print. Blend shades are predictions. Blending on U1 retains the existing 0.4 mm nozzle requirement. Other output slicers turn this mode off.

Verification covers the browser sample/apply/export flow, model/PETG exclusion (including same-colour PLA/PETG), slot swapping, compatible PETG profile selection, conflicting object settings and ordinary four-colour regression tests. The installed Snapmaker Orca CLI cannot provide slice confirmation: it fails on both this export and ordinary mixed/solid control exports. This demo has not been physically printed or verified by a successful native slice.

Production is unchanged. This work is isolated on `codex/petg-interface-demo` and deployed to a separate review alias.
