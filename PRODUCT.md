# YAB3D
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People preparing painted and textured 3D models for multicolour printing. The owner tests on Snapmaker U1 and Bambu H2C and wants straightforward object editing, efficient plate use and understandable colour decisions.

## Product Purpose
Prepare existing models for another slicer or printer, arrange their parts and map their colours to available filament. The product exports projects; destination slicers still slice and validate them.

## Stack
Existing static HTML and JavaScript, module workers and local browser processing, deployed on Netlify. Reuse the tested conversion engines in an independently published alternative interface.

## Capabilities and Constraints
Preserve converter, Full Spectrum, bulk conversion, textured-model preparation, source settings, printer/nozzle choices, capacity handling, palette suggestions, exact colours, loaded reels, Spool Studio import, calibration, PETG interfaces, slot arrangement, object editing, filling, merged sequential groups, export, U1 filament sending and experimental reel-change planning. Models stay in the browser. Actual printer writes remain deliberate reviewed actions. Preview and physical print validation are different things.

## Brand Commitments
YAB3D name and existing mark. UK English. The owner explicitly authorises a new design and workflow for a separate test version while retaining all features.

## Product Principles
Keep the model visible. Make the next useful action clear. Put advanced choices in context. Preserve work and visible feedback. Explain colour approximations and export limitations accurately.

## Evidence on Hand
Current browser app, automated tests, real Stabby Pumpkin and Flippin Pumpkin files, and the owner's supplied screenshots. The user requests an evaluated and tested alternative, with design choices delegated to the builder.
